# 10.10 标准I-O

## 💡 一句话总结

> **C 标准 I/O 在底层读写之上提供 FILE 流、格式化与缓冲，使用方便但增加了缓冲状态。**

---

## 📝 简短解释

fopen/fclose 管理 FILE 流，fread/fwrite 处理数据块，fgets 等处理文本，printf 等负责格式化。FILE* 不是 Unix 描述符整数。

输出可能先进入用户态缓冲区，之后才通过系统调用传给内核。行缓冲、全缓冲和无缓冲会让显示时机不同。

fflush 推送库缓冲数据，不等于保证已持久写入物理存储；fclose 也需要检查是否报告写入错误。混用 stdio 和底层描述符操作容易因缓冲和偏移状态出错。

## 🔎 例子或图解

```text
printf → FILE 输出缓冲 → write → 内核 → 输出设备/文件

函数返回时，内容可能还在中间缓冲中。
```

## 🎯 关键要点

- FILE 流比描述符多了库层状态。
- 刷新用户缓冲与持久化到磁盘是不同保证。
