# 第 10 章 系统级 I/O

这一章学习程序怎样打开、读取、写入和共享文件，重点理解描述符、短读写与缓冲。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

文件操作采用 Unix/POSIX 模型。RIO 是教材提供的辅助包，不是系统自动提供的标准库。本章命令和 API 流程仅为教学说明。
