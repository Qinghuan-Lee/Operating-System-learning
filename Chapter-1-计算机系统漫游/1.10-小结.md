# 1.10 小结

## 💡 一句话总结

> **一个程序能运行起来，靠的是信息表示、程序翻译、处理器、存储系统、操作系统和输入输出设备的共同配合。**

---

## 📝 简短解释

### 1. 把 hello 的旅程串起来

```text
hello.c：用字节表示的源代码文本
    ↓ 预处理、编译、汇编、链接
hello：磁盘上的可执行文件
    ↓ shell 请求操作系统运行
创建运行环境，加载需要的代码和数据
    ↓
CPU 执行指令，使用寄存器、缓存和主存
    ↓
通过输出服务显示 hello, world
    ↓
程序退出，shell 继续等待命令
```

如果远程运行，输入和输出还会经过网络，而程序在远端执行。

### 2. 每节解决了什么问题？

| 小节 | 核心问题 | 核心答案 |
|------|----------|----------|
| 1.1 | 信息如何表示？ | 位序列加上解释它的上下文 |
| 1.2 | 源代码怎样变成可执行文件？ | 预处理、编译、汇编、链接 |
| 1.3 | 为什么理解翻译过程？ | 帮助优化、排错和安全编程 |
| 1.4 | 谁在执行程序？ | CPU 执行机器指令，其他部件配合 |
| 1.5 | 如何减少等待数据？ | 利用高速缓存和局部性 |
| 1.6 | 怎样兼顾速度和容量？ | 采用存储器层次结构 |
| 1.7 | 谁管理硬件资源？ | 操作系统及其提供的抽象 |
| 1.8 | 不同计算机怎样合作？ | 通过网络进行输入输出 |
| 1.9 | 哪些思想贯穿全书？ | Amdahl 定律、并发与并行、抽象 |

### 3. 避免几个容易混淆的地方

- **程序与进程**：程序文件存放在磁盘上，进程对应程序的一次运行。
- **内存与磁盘**：主存通常断电丢失内容，磁盘用于长期保存。
- **位序列与含义**：`01100001` 按无符号二进制整数解释是 97，按 ASCII 字符解释是 `a`；不能脱离具体指令集就把它说成某条指令，也不能脱离浮点格式就说它是某个浮点数。
- **链接与复制库代码**：静态链接可以把需要的库代码并入可执行文件；动态链接还会在加载或运行时关联共享库，不是所有库代码都必须复制进去。

最后两点也是对前两节入门说明的补充澄清。

## 🎯 关键要点
