# 1.5 高速缓存至关重要

## 💡 一句话总结

> **高速缓存把近期可能用到的指令和数据放在离 CPU 更近、访问更快的位置，减少 CPU 等待数据的时间。**

---

## 📝 简短解释

### 1. 为什么需要高速缓存？

CPU 运算很快，但从主存取数据相对较慢。如果每次都要等主存，CPU 就不能充分发挥速度。

可以把主存想成书架，缓存想成手边摆着常用书的小架子：容量小一点，却更容易拿到。

```text
CPU 需要数据
     ↓
在缓存中查找
     ├─ 命中：从缓存快速取得
     └─ 未命中：到下一层查找，并按缓存策略带回数据
```

### 2. 为什么小缓存能管用？

因为程序经常具有“局部性”：

| 类型 | 通俗解释 | 例子 |
|------|----------|------|
| 时间局部性 | 刚用过的，很可能还会用 | 循环里反复执行同一段指令 |
| 空间局部性 | 用了某个位置，很可能接着用附近位置 | 依次读取数组的相邻元素 |

缓存通常以一块数据（缓存行）为单位搬运，所以读取一个元素时，也可能顺便带回附近元素。

### 3. L1、L2、L3 是什么？

它们是不同级别的缓存。典型情况下，L1 较小、较快；更低层的缓存容量更大，访问也更慢。具体容量和速度因处理器而异。

CPU 高速缓存通常使用 SRAM，主存通常使用 DRAM；此时先记住“技术不同，速度和成本也不同”即可。

## 🎯 关键要点

| 概念 | 解释 |
|------|------|
| Cache | 保存近期可能使用的信息的高速存储器 |
| 命中 | 需要的数据已经在该层缓存里 |
| 未命中 | 需要到下一层获取数据 |
| 局部性 | 小容量缓存仍然能有效工作的原因 |
