# 1.1 信息就是位 + 上下文

## 💡 核心概念

> **计算机中所有信息（程序、数据、文档）都是由0和1组成的位（bit）序列，同一段位序列在不同上下文中可以表示不同的含义。**

---

## 📝 详细解释

### 1. 什么是位 (bit)?

- 位是计算机中最小的信息单位
- 只有两种可能的值：`0` 或 `1`
- 例如：`10110100` 就是8个位（也叫1个字节）

### 2. 为什么用位表示？

- 电子硬件容易区分两种状态：高电压(1) / 低电压(0)
- 这使得信息的存储和传输非常可靠

### 3. 上下文的重要性

同一串位 `01100001` 在不同上下文中含义完全不同：

```
┌─────────────────────────────────────────────────────┐
│         同一个位序列，不同的含义                        │
├─────────────────────────────────────────────────────┤
│  作为整数: 97                                        │
│  作为字符: 'a' (ASCII码)                              │
│  作为指令: add 操作                                    │
│  作为浮点数: 某个极小的数值                             │
└─────────────────────────────────────────────────────┘
```

### 4. 源程序示例

当你写了一个简单的C程序：

```c
#include <stdio.h>
int main() {
    printf("hello, world\n");
    return 0;
}
```

这个程序以**字节序列**的形式存储在磁盘上，每个字节都是一个整数值，对应某个字符。

---

## 🎯 关键要点

| 概念 | 解释 |
|------|------|
| **位 (bit)** | 0或1，最小信息单位 |
| **字节 (byte)** | 8个位，最基本的存储单元 |
| **上下文 (context)** | 决定位序列含义的环境 |
