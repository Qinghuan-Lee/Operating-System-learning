# 11.4 套接字接口

## 💡 一句话总结

> **套接字 API 建立连接端点，连接成功后便可通过描述符收发字节。**

---

## 📝 简短解释

**地址与解析。** sockaddr 一类结构保存地址，getaddrinfo 把主机和服务名转成候选地址，getnameinfo 做相应的可打印名称转换。候选地址可能不止一个，应按需尝试。

**客户端。** socket 创建端点，connect 发起连接，随后读写，最后 close。

**服务器。** socket 后用 bind 绑定本地地址，listen 进入监听状态，accept 接受连接并返回新的连接描述符。监听描述符继续接收其他连接，不能和某个客户端连接描述符混用。

**辅助函数与 echo。** 教材的 open_clientfd/open_listenfd 封装建立端点的步骤；echo 服务器把读到的字节发回。处理时仍要检查错误、短读写和连接结束。

对端正常关闭发送方向后，待已缓冲字节读完，read 返回 0；不是收到一个名为 EOF 的特殊字节。

## 🔎 例子或图解

```text
客户端                     服务器
getaddrinfo                getaddrinfo
socket                     socket → bind → listen
connect ─────────────────→ accept
read/write ←────────────→ 新连接描述符 read/write
close                      close（连接描述符）
                           监听描述符继续等待
```

## 🎯 关键要点

- accept 返回新描述符，原监听描述符仍有效。
- 建立连接与解释应用消息是两层工作。
- 关闭发送方向后，另一个方向仍可能继续传输。
