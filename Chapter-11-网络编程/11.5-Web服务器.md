# 11.5 Web服务器

## 💡 一句话总结

> **教材中的 Web 交互用 HTTP 请求描述资源，再由服务器返回状态、头部和内容。**

---

## 📝 简短解释

**资源和内容。** URL 描述要访问的位置；静态内容来自已有文件，动态内容按请求计算生成。内容类型帮助客户端解释字节，例如文本或图片。

**HTTP/1.x 事务。** 请求包含方法、目标和版本等信息；响应包含状态行、头部和可选正文。头部以空行结束，正文长度或结束方式由协议规则确定。

**动态内容。** 教材通过 CGI 演示服务器准备环境、启动处理程序并转发输出。它是一种教学中的动态内容接口，并非所有 Web 服务都必须这样实现。

HTTP 层的成功或错误码描述应用结果，与 TCP 是否建立成功不同。这里只讲本书使用的协议子集，不把它当作全部 HTTP 版本的编码方式。

## 🔎 例子或图解

```text
示例请求行：GET /index.html HTTP/1.0

示例响应结构：
HTTP/1.0 200 OK
Content-Type: text/plain
Content-Length: 5

hello
```
上面的换行用于展示结构；实际 HTTP/1.x 行结束使用规定的 CRLF。

## 🎯 关键要点

- 连接成功不意味着资源一定存在。
- 头部结束与正文结束要分别判断。
- 动态内容是服务器计算后产生的内容。
