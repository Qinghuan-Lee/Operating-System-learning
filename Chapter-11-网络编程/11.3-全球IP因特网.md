# 11.3 全球IP因特网

## 💡 一句话总结

> **IP 地址、域名和端口共同帮助程序找到通信对象，TCP 提供有序的连接字节流。**

---

## 📝 简短解释

IP 地址标识网络接口位置，教材主要用 IPv4 的 32 位地址讲解；域名通过名称解析得到一个或多个地址，不保证永久一一对应。

端口把通信交给主机上的服务端点。TCP 连接通常用协议及两端的 IP 和端口组合区分，客户端常使用临时端口。

网络字节序是大端序，处理二进制地址和端口时需要相应转换，不能依赖本机恰好采用同样的字节顺序。

TCP 提供有序、可靠的字节流，但不保留应用 write 的消息边界，也不能保证连接永远不会故障；它自身不等于加密传输。

## 🔎 例子或图解

```text
域名 → 名称解析 → IP 地址
IP + 端口 → 通信端点

客户端 IP:临时端口 ← TCP 字节流 → 服务端 IP:服务端口
```

## 🎯 关键要点

- 域名、IP 和端口用途不同。
- 可靠字节流仍需要应用定义消息边界。
