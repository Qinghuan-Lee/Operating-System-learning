# 第 11 章 网络编程

这一章把网络当作字节流 I/O，学习客户端、服务器、套接字和教材中的小型 Web 服务器。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

以 TCP、POSIX 套接字和教材的 HTTP/1.x 示例为主。笔记没有部署服务器，TINY 是教学模型。网络完整性与安全性不是同一保证。
