# 第 7 章 链接

这一章解释多个源文件和库如何拼成可运行的程序，以及“找不到函数”“重复定义”和地址修正从何而来。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

格式和工具以教材的 Linux ELF 为主。工具命令是学习示例；静态库提取、动态符号解析与平台和构建选项有关。
