# 7.5 符号和符号表

## 💡 一句话总结

> **符号表给函数和静态存储对象建立名字与位置之间的联系。**

---

## 📝 简短解释

模块可以定义供其他模块使用的全局符号，也可以引用别处定义的外部符号。文件作用域 static 函数或变量一般只在当前模块可见。

这里的“局部符号”是链接范围的概念，不等于“函数里的普通局部变量”。函数内 static 变量具有静态存储期，也可能对应目标文件中的局部符号。

符号条目还记录类型、所属节和相对位置等信息。链接器依据这些信息解析名字，而不是理解完整的 C 语义。

## 🔎 例子或图解

```text
模块 A：定义 main，引用 helper
模块 B：定义 helper，定义本模块私有的 cache

全局可连接名字与源代码块作用域不是同一概念。
```

## 🎯 关键要点

- 作用域、链接属性、存储期需要分开理解。
- extern 声明不等于提供实体定义。
