# 7.1 编译器驱动程序

## 💡 一句话总结

> **gcc 这类驱动程序协调预处理、编译、汇编和链接，把多个源文件构建成可执行文件。**

---

## 📝 简短解释

命令中的 gcc 不只是狭义的“把 C 变成汇编”的编译器，它还负责调用相关工具，并为链接补充启动文件和库等参数。

不同源文件先独立变成目标文件，再由链接器组合。修改一个源文件时，可以只重新编译受影响的部分，再链接整个程序。

`-c` 表示生成目标文件而不进行最终链接；直接给多个源文件则可完成整个构建链。

## 🔎 例子或图解

```text
main.c → main.o ─┐
                ├→ 链接 → prog
sum.c  → sum.o ──┘

示例：gcc main.c sum.c -o prog
```

## 🎯 关键要点

- 驱动程序协调多个阶段。
- 分离编译让大项目更容易组织和增量构建。
