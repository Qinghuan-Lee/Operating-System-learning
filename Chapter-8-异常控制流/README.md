# 第 8 章 异常控制流

程序执行不只会按顺序、分支和函数调用前进。中断、系统调用、进程切换和信号会改变控制流。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

API 以教材的 Linux/POSIX 为背景。大写 Fork、Wait 等通常是教材的错误处理包装函数，不是标准接口本名。本章的“异常”也不等于单指 C++ 的 throw。
