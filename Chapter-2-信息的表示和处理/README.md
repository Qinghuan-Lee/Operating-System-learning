# 第 2 章 信息的表示和处理

这一章回答：同样的 0 和 1，怎样表示整数、小数、字符和地址？难点是区分数学上的数与有限位宽的机器表示。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

先备知识：会做简单的乘法、幂运算，知道变量和数组。这里的 4 位、8 位例子是教学模型，不代表 C 表达式一定按这个位宽计算。
