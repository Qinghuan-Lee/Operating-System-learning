# 第 9 章 虚拟内存

这一章把程序看到的地址与真实物理内存连接起来，再学习内存映射、动态分配和常见内存错误。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

先掌握指针、数组、缓存和进程。图中的页大小与地址位数是教学示例；教材 Core i7 的具体参数是书中案例，不代表所有机器。
