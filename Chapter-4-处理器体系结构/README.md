# 第 4 章 处理器体系结构

这一章用简化的 Y86-64 处理器说明：机器指令如何由电路实现，以及流水线为什么能提高吞吐量。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

Y86-64 是教学指令集，不是电脑可以直接执行的 x86-64 程序。HCL 用于描述硬件控制逻辑，不是按语句顺序执行的普通 C 程序。
