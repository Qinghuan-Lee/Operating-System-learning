# 3.5 算术和逻辑操作

## 💡 一句话总结

> **CPU 用加减、位运算、移位等简单指令组成复杂计算，部分指令还更新条件标志。**

---

## 📝 简短解释

一元操作有取负、取反等；二元操作有加、减、与、或、异或等。AT&T 双操作数算术通常把结果放在后一个操作数中。

`leaq` 使用寻址形式计算一个数值，但不读取该地址的内存，因此除了算指针，也常用于简单乘加。

逻辑右移补零，算术右移补符号位。乘除法还可能使用固定寄存器组合：某些 64 位乘法产生 128 位结果，放在 `%rdx:%rax` 中。

先掌握普通加减和地址计算；特殊乘除指令要同时追踪隐含输入输出寄存器。

## 🔎 例子或图解

```text
若 rdi = 7：
leaq (%rdi,%rdi,4), %rax
结果 rax = 7 + 7×4 = 35，不访问地址 35

subq %rbx, %rax
结果 rax = 原 rax - rbx
```

## 🎯 关键要点

- lea 算地址形式的表达式，不等于加载数据。
- 算术指令可能同时改变数据和条件码。
