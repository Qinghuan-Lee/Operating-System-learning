# 3.4 访问信息

## 💡 一句话总结

> **机器指令从立即数、寄存器或内存取操作数，寻址表达式用来算出内存位置。**

---

## 📝 简短解释

立即数是指令中的常量；寄存器操作数是 CPU 内部的值；内存操作数需要先算地址，再访问那个位置。

AT&T 的 `D(Rb,Ri,S)` 表示 `D + Rb + Ri×S`，S 常取 1、2、4、8。它很适合访问数组。

`mov` 是复制而非搬走：源值通常仍保留。扩展加载需要区分补零和符号扩展。x86-64 中写入 32 位通用寄存器会清零对应 64 位寄存器的高 32 位，写入 8/16 位部分则不是同样的规则。

`pushq` 和 `popq` 把数据放入或取出栈；常见 8 字节压栈使 `%rsp` 减 8，弹栈使它加 8。

## 🔎 例子或图解

```text
若 rdi = 1000，rcx = 3：
8(%rdi,%rcx,4) 的地址 = 1000 + 3×4 + 8 = 1020

movq %rax, %rbx    寄存器 → 寄存器
movq (%rdi), %rax  指针所指内存 → 寄存器
```

## 🎯 关键要点

- 地址本身与地址处保存的内容不同。
- 普通 mov 通常不能两个操作数都为内存。
- 栈指针指向栈顶，压栈通常向低地址增长。
