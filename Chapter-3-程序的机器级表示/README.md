# 第 3 章 程序的机器级表示

这一章把 C 代码拆成 CPU 能执行的操作，学习读懂汇编、函数调用和数据布局。目标是看懂编译器输出。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

示例采用教材的 Linux/x86-64、System V AMD64 调用约定和 AT&T 汇编语法。Windows x64 的参数寄存器等规则不同。汇编片段用于解释，不是完整可执行程序。
