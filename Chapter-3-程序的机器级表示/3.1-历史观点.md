# 3.1 历史观点

## 💡 一句话总结

> **x86-64 是在早期 x86 基础上逐步扩展而来的，历史兼容性解释了许多看似不规则的设计。**

---

## 📝 简短解释

早期 x86 以 16 位为主，后来发展出 32 位 IA32，再扩展到 64 位 x86-64。位宽变化带来了更大的地址能力和更多寄存器等变化。

寄存器名称保留着历史痕迹：`%rax`、`%eax`、`%ax` 是同一寄存器的不同宽度视图，不是互不相关的三个盒子。

**指令集架构**规定指令的可见效果；**微体系结构**是芯片内部怎样完成这些效果。同一种指令集可以有多种硬件实现，因此“程序能运行”和“运行得一样快”是两个问题。

## 🔎 例子或图解

```text
16 位 x86 → 32 位 IA32 → 64 位 x86-64

一个寄存器的局部视图：
rax：64 位
└─ eax：低 32 位
   └─ ax：低 16 位
```

## 🎯 关键要点

- 历史包袱使寄存器和指令命名不完全整齐。
- 本章以 x86-64 为主，不要求记住处理器型号年表。
