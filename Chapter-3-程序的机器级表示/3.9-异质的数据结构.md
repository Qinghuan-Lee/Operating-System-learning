# 3.9 异质的数据结构

## 💡 一句话总结

> **结构体把不同成员放在同一对象的不同位置，联合体让成员复用同一片空间，对齐会带来填充。**

---

## 📝 简短解释

结构体成员通常按声明顺序布局，但为了满足成员对齐要求，编译器可能在成员之间和尾部加入填充。对象总大小不一定等于成员大小相加。

访问成员时使用“结构体起始地址＋固定偏移”；数组中的每个结构体都按整个结构体大小前进，尾部填充有助于下一个元素正确对齐。

联合体各成员从同一位置开始，存储空间至少容纳最大的成员，还需满足对齐。它并不同时保存所有成员的独立值。

要查看当前平台实际布局，用 sizeof 和 offsetof；跨平台存储文件时不能只把内存布局当成稳定的数据格式。

## 🔎 例子或图解

```text
常见布局：struct { char c; int x; };
偏移 0：c
偏移 1～3：填充
偏移 4～7：x
总计 8 字节（假设 int 大小和对齐均为 4）
```

## 🎯 关键要点

- 对齐是地址位置的要求，填充是为满足要求留下的空间。
- struct 成员各有空间，union 成员复用空间。
