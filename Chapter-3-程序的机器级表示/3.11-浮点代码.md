# 3.11 浮点代码

## 💡 一句话总结

> **浮点计算使用专门的寄存器和指令，参数传递与比较规则也不同于普通整数。**

---

## 📝 简短解释

教材以 AVX 风格的标量指令讲解浮点数。XMM 寄存器虽然宽于单个 float 或 double，但标量操作可以只使用其中的低位部分；更宽不代表每次都在做向量运算。

浮点传送、算术和整数/浮点转换各有对应指令。教材调用约定常用 XMM 寄存器传递浮点参数和返回值，不能套用整数参数寄存器表。

浮点比较还要处理 NaN：它与普通数之间是无序的。编译器可能需要结合多个标志位实现 C 的比较语义。

取负或绝对值有时通过处理符号位实现，但普通数值类型转换不等同于重新解释位模式。

## 🔎 例子或图解

```text
整数 3  ──数值转换──→ 浮点数 3.0
整数位模式 ──原样解释为浮点──→ 通常完全不同的数值

标量操作：处理一个浮点值
向量操作：同一指令处理多个浮点值
```

## 🎯 关键要点

- 浮点数据主要使用 XMM 等寄存器。
- 标量与 SIMD 的区别在于处理的数据个数。
- 比较时不能忽略 NaN 的无序情况。
