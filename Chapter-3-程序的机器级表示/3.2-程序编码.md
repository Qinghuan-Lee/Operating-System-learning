# 3.2 程序编码

## 💡 一句话总结

> **编译器把 C 翻译成汇编，汇编器生成机器码，反汇编工具则把机器码显示成人能读的指令。**

---

## 📝 简短解释

源代码描述算法；汇编代码描述寄存器、内存和控制流；机器码是处理器实际识别的字节。

用 `gcc -Og -S example.c` 可以观察汇编输出，`gcc -Og -c example.c` 生成目标文件，再用 `objdump -d example.o` 反汇编。这里是教材式 Linux 命令示例，未替你运行。

AT&T 语法通常按“源、目的”的顺序书写，寄存器前加 `%`，立即数前加 `$`。Intel 语法的常见操作数顺序相反，阅读时先确认采用哪种语法。

优化会改写控制结构，不能要求源代码的每一行都对应固定的一条指令。

## 🔎 例子或图解

```text
C 源码 → 汇编文本 → 机器码字节
                       ↓ 反汇编
                    指令文本

movq $5, %rax    # AT&T：把 5 放入 rax
```

## 🎯 关键要点

- .s 是汇编文本，.o 是目标文件。
- 调试信息与优化程度影响观察源码的难易。
- 一条指令可能由多个字节编码。
