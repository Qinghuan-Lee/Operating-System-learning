# 3.12 小结

## 💡 一句话总结

> **读汇编时追踪数据位置、运算宽度和控制流，就能逐步还原 C 程序的行为。**

---

## 📝 简短解释

先认出寄存器、立即数和内存操作数，再判断每条指令修改了什么。接着标出分支和循环，最后结合调用约定识别参数、返回值与局部变量。

数组、结构体与指针最终会表现为地址计算；函数与递归最终会表现为跳转、寄存器约定和栈上的状态保存。

不必一次背完全部指令。先练习把短小函数的输入、过程、输出对应起来，再分析优化过的复杂代码。

## 🔎 例子或图解

```text
读一段汇编：
输入在哪 → 每条指令修改什么 → 分支怎么走 → 结果去哪
           ↘ 内存地址如何算、访问多少字节 ↗
```

## 🎯 关键要点

- 先认数据流，再认控制结构。
- 始终标明使用的架构和调用约定。
- 优化后的汇编不必保留源码的表面结构。
