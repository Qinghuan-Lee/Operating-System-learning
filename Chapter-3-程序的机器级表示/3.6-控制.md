# 3.6 控制

## 💡 一句话总结

> **分支和循环最终依靠比较结果、条件码以及改变指令位置的跳转来实现。**

---

## 📝 简短解释

**条件码。** ZF 表示结果为零，SF 反映符号，CF 反映无符号进位或借位，OF 反映有符号溢出。`cmp` 类似做减法但只留标志；`test` 类似做位与但不保存算术结果。

**分支。** 条件跳转选择接下来执行哪里；条件传送选择保存哪个结果。对应有符号和无符号比较的跳转不同。条件传送并非总能安全替代 if，例如不能提前执行本来不会发生的非法内存读取。

**循环与 switch。** 循环把条件测试和向前面跳转连起来；switch 可能变成连续比较，也可能使用跳转表。跳转编码还可能使用相对当前指令位置的位移。

读汇编时先找入口、条件、两个分支和汇合点，再还原高级语言结构。

## 🔎 例子或图解

```text
测试条件
  ├─ 真 → 执行循环体 → 更新变量 ─┐
  │                             │
  └─ 假 → 离开循环              └→ 回到测试
```

## 🎯 关键要点

- 有符号比较和无符号比较不能随意换。
- 条件码是上一次相关指令留下的信息。
- 编译器有多种实现同一控制结构的方式。
