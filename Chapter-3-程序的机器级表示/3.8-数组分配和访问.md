# 3.8 数组分配和访问

## 💡 一句话总结

> **数组元素连续排列，元素地址等于起始地址加上索引乘元素大小。**

---

## 📝 简短解释

对元素大小为 L 的一维数组，`a[i]` 的地址是 `base + i×L`。指针加 1 前进一个元素，不一定是一个字节。

C 的真正二维数组按行连续存放：`a[R][C]` 中 `a[i][j]` 的偏移是 `(i×C+j)×L`。数组的数组与“指向若干行的指针数组”布局不同，不能混用。

固定大小数组的步长可能在编译时确定；变长数组的步长需在运行时用实际维度计算。数组表达式在很多场合转换为首元素指针，但数组对象本身不是指针变量。

下标访问需要保证合法范围，机器地址计算不会自动替你做 C 数组边界检查。

## 🔎 例子或图解

```text
int a[2][3]，假设 int 为 4 字节：
内存顺序：a00 a01 a02 a10 a11 a12
相对偏移： 0   4   8  12  16  20

a[1][2]：偏移 (1×3+2)×4 = 20 字节
```

## 🎯 关键要点

- 步长取决于元素类型。
- 多维数组按行展开。
- sizeof 数组与 sizeof 指针不是同一含义。
