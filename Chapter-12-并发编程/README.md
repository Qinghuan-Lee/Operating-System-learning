# 第 12 章 并发编程

这一章讨论怎样同时推进多个任务，以及多个执行流共享状态时如何保持正确。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

示例以 POSIX 进程和线程接口为背景。伪代码说明顺序与同步关系，不是可直接复制的完整服务器。普通 C 共享变量的数据竞争不能只当成“偶尔少算一次”。
