# 第 5 章 优化程序性能

这一章讨论怎样让已经正确的程序做更少的工作，并更好地利用处理器。先测量、再定位、再修改。

学习方式：每天读一个能消化的小主题，先看一句话总结，再看解释和例子，最后用自己的话回答思考题。内容较长的一级小节可拆成多天。

速度结论与硬件、编译选项和输入有关。笔记中的数字是解释用例，不是你电脑的实测值。所有变换都以保持所需程序语义为前提。
