# 5.7 理解现代处理器

## 💡 一句话总结

> **处理器可以重叠执行独立操作，但一个操作必须等待所需输入，数据依赖决定了速度下限。**

---

## 📝 简短解释

指令控制部分取指、预测和安排执行；多个功能单元执行整数、浮点、加载和存储等操作。内部可以乱序执行，同时维持架构要求的可见结果。

**延迟**是一次操作得到结果所需时间，**吞吐能力**是单位时间能开始或完成多少操作；流水化单元可能延迟多周期却每周期接收新操作。

把操作画成数据流图，节点是操作，箭头是依赖。最长的依赖链是关键路径，会限制串行部分速度。独立操作多了以后，功能单元数量等资源又成为限制。

## 🔎 例子或图解

```text
依赖链：a → 加法 → 加法 → 加法
不能同时算尚未得到输入的后续加法。

独立链：a → 加法
        b → 加法
可由可用硬件重叠处理。
```

## 🎯 关键要点

- 延迟下限与资源吞吐下限不同。
- 乱序执行不会凭空消除真实数据依赖。
